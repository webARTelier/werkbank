flexNeighborMarker

Marks flex items that share a visual row so CSS can style row neighbours.

A wrapping flex row where each item that is followed by a neighbour in the same visual row shows a divider — but the last item of every row never does. Resize the window: as the items reflow onto more or fewer rows, the dividers recompute to match the live layout, something pure CSS :not(:last-child) cannot express.
