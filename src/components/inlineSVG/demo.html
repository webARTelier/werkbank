inlineSVG

Replaces an <img> that points at an .svg file with a real, inline <svg> node.

Once inlined, an SVG becomes an ordinary part of the document: it can inherit currentColor and be styled by page CSS. The three copies of the same file below are tinted purely by the color of their parent — proof the graphic is live SVG, not a sealed <img>.

Hover me. The inlined icon recolours on :hover via CSS on its wrapper — impossible with an <img>.
