dataTable

Sortable columns, and a table that survives a narrow screen.

Sortable columns

Four columns, three of them sortable, sorted by Last check on load. Click a header to sort by it: a fresh column starts ascending, the sorted one flips. The Requests and Median cells are formatted for people and carry a data-datatable-value for the machine; the dates sort by their <time datetime>. Two rows have gaps — an empty cell sorts last in both directions, because it is not a small value but no value.

Wide, with a sticky header and a sticky first column

Eleven columns, capped at 18rem tall — more than fits, on purpose. Scroll the box sideways: the region column stays put, and it carries whichever colour its row has — a stripe, or the one under your pointer — so it covers the columns passing underneath. Scroll it downwards and the header stays. The height is what makes that work: a sticky cell sticks inside its own scroll container, so without a cap the header would have nothing to stick to.

Stacked below 575px

The same kind of table, with data-datatable-stacked. Narrow the window below 575px and every row becomes a card of label/value pairs, with the header row surviving as a bar of sort chips — sorting is the one part of a table a phone wants more of, not less. The labels on the cards are written by the module from the header, and so are the explicit table roles, without which the cards would stop being a table for a screen reader. That is why the layout is keyed off data-datatable-ready: without the module, this stays the scrolling table above.

No controls: the box itself takes the focus

Eleven columns again, this time with no sortable one — so the module adds no buttons, and nothing inside the box can take focus. Since the table is wider than the box, the module therefore makes the box a tab stop and names it by its caption, and the arrow keys scroll it. Tab to it and hold →. Make the window wide enough for the table to fit and the tab stop goes away again — a box that fits is not a dead stop in the tab order.
