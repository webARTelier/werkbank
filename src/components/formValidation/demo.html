formValidation

Accessible inline validation built on the native Constraint Validation API.

Try submitting it empty. An error summary appears at the top and focus jumps to it; its links jump to each field, every invalid field gets an inline message, and both the summary and the messages clear one by one as you fix them. The messages follow <html lang> (this page is en) and come from the module's built-in defaults, which a single CMS-editable JSON block can override (here two English texts are reworded), while individual fields can override further — the email below carries a custom message.
