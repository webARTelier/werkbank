dateInputFormat

Formats a date field to DD.MM.YYYY while typing.

Single field: type digits and the dots appear automatically. Try editing in the middle, or backspacing onto a dot — the caret stays where you expect.

Format: DD.MM.YYYY

Wrapper scope: data-js-behavior sits on the surrounding element, so every data-dateinputformat field inside it is formatted.

Format: DD.MM.YYYY

Per-field mask: give data-dateinputformat a pattern value to override the mask for that field — here MM/DD/YYYY. Different locales can coexist on one page.

Format: MM/DD/YYYY
