marquee

An infinitely scrolling content strip (news ticker), added as a progressive enhancement on a static row.

Watch the strips scroll. Hovering a strip pauses it, tabbing into one pauses it too, and the Pause button parks it until you press play again. With prefers-reduced-motion: reduce every strip starts paused.

Default ticker

No options set: scrolls to the left, always, one cycle every 8 seconds. The link inside shows the focus pause.

Only while it overflows

data-marquee-start="overflow": the strip animates only while its content is wider than the box. Drag the handle in the bottom-right corner — make the box wide enough and the marquee stops and cleans up its clones; narrow it and it starts again.

Constant pixel speed

data-marquee-speed="80": both strips move at the same 80 px/s even though their text differs in length. With data-marquee-duration the shorter one would finish its cycle in the same time and so appear slower.

Short line.

A noticeably longer line of ticker text that still travels at exactly the same pixel speed as the short one above.

Countdown inside the ticker

The countdown component is placed inside the marquee. The marquee clones its track for the seamless loop and countdown.js mirrors its live values into the (inert) clones, so every copy stays in sync — the documented marquee ↔ countdown integration. Seconds are omitted on purpose: a per-second digit width change would force the marquee to re-measure constantly, so a ticker reads best on days / hours / minutes.
