dev_dashboard

One bar at the bottom edge, one icon per tool. The page information is read out permanently, the accessibility inspector and the overflow check carry a green or red mark with a count, and every tool that needs room opens its panel over this page. This demo gives each of them something to find.

Page information

The four values on the left of the bar are custom properties: --viewportName, --navstate, --density and --input. The project declares them on :root; the dashboard reads them off <body>, where they inherit. This page declares them itself, in the stylesheet in its head — resize the window and the first two change. A page that declares none of them shows an amber ? per missing token, with the property name in its tooltip.

Horizontal overflow

The box below is 108vw wide, so it pushes a horizontal scrollbar. That is the permanent case, and the reason the ↔ icon is red when this page loads. The list is measured again on every window resize, and the button adds a second offender for a manual scan again.

108vw — wider than the document on purpose

QR code

The QR icon encodes this page's URL in the page itself — no request goes anywhere, which is what lets the dashboard keep the tool rule of never talking to a third party. Note the code is only useful on another device if the page is served on an address that device can reach: localhost means the machine doing the scanning.

srcset measurement

The 🖼 icon opens the panel; pick images then hands the page over: every image you click joins the selection and gets a numbered badge, a second click on it drops it again, and Esc or done brings the panel back with the list. measure sweeps the viewport range in a probe frame of its own. This needs a local server — over file:// the frame cannot be read, and the panel says so.

The four images below additionally carry data-dev-srcset, which pre-selects them at load with the attribute's value as their label — that is all the attribute still does. Each one is a different layout behaviour.

2 · text column, max. 760px

Only the first tile is pre-selected: three tiles of equal width are one measurement, not three. Click the others if you want to see for yourself that they measure the same.

4 · fixed 120px avatar

5 · inside a link, not pre-selected

Picking swallows the click: selecting this image does not follow the link, and the link works again the moment picking ends. Its label falls back to the file name, since there is no attribute to read one from.

Form filler

The 📝 icon lists every form on this page. fill writes Gandalf the Grey into one of them, fill all into all three, and reset puts every field back the way it was. Nothing is submitted — the submit button stays yours to press.

The form below is deliberately awkward: a five-digit pattern, a min on the date that no Third Age birthday clears, a maxlength shorter than the quote, a number field whose missing step still rules out 19.54, a text field whose placeholder is the only clue to the date format it wants, a group of checkboxes, a readonly field and two fields that steer the filler with data-dev-form. The panel reports each of those, and the browser's own verdict on the value that was written.
